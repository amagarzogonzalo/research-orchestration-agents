## How to reproduce

```bash
python -m venv .venv && .venv\Scripts\activate
pip install -e ".[dev, providers]"
pip install trafilatura playwright && python -m playwright install chromium
cp .env.example .env   # fill GROQ/MISTRAL/OPENROUTER/GEMINI keys (free tier)
python - <<'PY'
import asyncio
from knowledge_engine.engine import ResearchEngine
asyncio.run(ResearchEngine(store_root="research_store").research(
    "Explain the top 7 relevant papers for attention in LLMs",
    thread_id="top7-attention-llms",
))
PY
```

Artifacts land under `research_store/`; move the folder anywhere (files-only).
